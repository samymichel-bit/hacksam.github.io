# HackSam Digital Solutions — Portfolio

Portfolio professionnel de Samy (HackSam), développeur web & solutions digitales à Yaoundé, Cameroun.

## 🚀 Aperçu

Site vitrine présentant les compétences, services et réalisations de HackSam Digital Solutions :
- Sites web & applications
- Intelligence Artificielle & Automatisation
- Applications mobiles
- Logiciels sur mesure
- Infrastructure & maintenance

## 📂 Structure du projet

```
portfolio/
├── index.html              → Page principale du portfolio
├── style.css               → Styles du portfolio
├── script.js               → Interactions (nav, scroll, formulaire Web3Forms)
├── 404.html                → Page d'erreur personnalisée
├── sitemap.xml             → Référencement SEO
├── robots.txt              → Configuration crawl SEO
├── images/
│   └── ma-photo.png        → Photo de profil
└── projects/
    ├── zangalewe.html              → Site restaurant premium (Bastos, Yaoundé)
    ├── betmind-pro-v6-online.html  → Application analyse sportive (mode démo)
    └── ecommerce-demo.html         → Boutique e-commerce (démo, prix FCFA)
```

## 🛠 Technologies

- **Frontend** : HTML5, CSS3, JavaScript (vanilla), SVG
- **Formulaire** : Web3Forms (envoi d'emails sans backend)
- **Chat** : WhatsApp Business API (liens directs)
- **Design** : Inter, design system orange (#FF7A00) premium

## ▶️ Lancer en local

Ouvrez simplement `index.html` dans un navigateur, ou servez le dossier :

```bash
python3 -m http.server 8000
```

Puis visitez http://localhost:8000
